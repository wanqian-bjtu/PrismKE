# 许可与署名

## OGL-UK-3.0

Building Digital UK 与 DVLA 报告按 Open Government Licence v3.0 使用，除原文另有声明的
第三方内容外。使用时应标注来源和 Crown copyright：

<https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/>

## NIST-USG-PD

NIST 员工作品在美国境内不受版权保护；NIST 对境外可能主张的权利提供全球、永久、免版税
的转载与演绎许可。引用时保留出版物名称、编号、作者和 DOI：

<https://www.nist.gov/open/copyright-fair-use-and-licensing-statements-srd-data-software-and-technical-series-publications>

## CC-BY-4.0

ACL Anthology 自 2016 年起的材料按 Creative Commons Attribution 4.0 发布。必须保留作者、
论文题目、会议、年份、DOI 和许可链接：

<https://aclanthology.org/faq/copyright/>

## CC0-1.0

Wikidata 主命名空间的结构化数据按 Creative Commons Zero 发布。虽然不强制署名，本数据集
仍记录实体 URI、检索日期和 Wikidata 来源：

<https://www.wikidata.org/wiki/Wikidata:Licensing>
