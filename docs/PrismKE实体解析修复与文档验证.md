# 实体解析修复与真实文档验证

实体解析策略为`entity-resolution-v2`，版本号与发布标签不变。原运行可通过`show-run`查看，但旧策略运行不得恢复或继续审核，应重新执行输入。

## 名称召回与安全治理

解析器同时查询带上下文的实体提及和名称/类型向量，两路各取Top-K后按实体ID合并。候选保留字符串名称分数，并新增`semantic_name_score`原始余弦分数，旧结果中默认为空。跨中文/拉丁文字名称使用语义名称分数辅助重排，但不因此直接自动链接。

自动链接阈值0.88、审核阈值0.65、候选差距0.08不变。跨语言名称余弦不低于0.65，或召回余弦不低于0.85且上下文分数不低于0.85的疑似重复记录，不因综合分偏低而自动创建NIL。它们可以进入审核，不能被算作自动链接成功。

批次精确匹配表只接收自动接受的实际实体；待审核新实体是草稿，未选中的NIL不参与后续匹配。审核草稿仍支持人工新建，但图提交只包含正式Claim实际引用的实体。

## 验证顺序

1. 运行完整离线测试，含跨语言正负例、真正NIL、批次草稿污染和旧策略只读测试。
2. 使用原答案与原15实体候选库，分别运行固定库和顺序导入基线，保存到新目录。候选排名、自动链接、NIL、审核与聚类分别报告。
3. 四条已知重复创建不再自动新建、未增加错误自动链接且Top-10召回不下降后，才执行公开材料的真实文档测试。
4. 文档测试强制使用隔离JSON图谱，不连接生产Neo4j。人工审核不由标准答案代替；未完成审核的任务正常保留。

文档调用须逐请求记录实际用量并预估请求预算，接近9万Token停止新增请求，为重试和在途调用预留空间，整轮目标10万以内。配置错误、额度不足或用量缺失时停止，不主动充值。原文、标注及详细报告保留在忽略的`runtime`，不得提交密钥或完整向量。

47条已标注对象不构成全文穷尽答案；文档测试只能报告这些对象的观察情况与人工问题清单，不能将其他真实实体自动视为误报或宣称全文Precision/F1。

## 真实文档验证入口

`prismke validate-documents MANIFEST --output 新运行目录`读取服务器配置，强制使用隔离JSON后端、真实BGE-M3、PaddleOCR和OpenAI-compatible文本/视觉服务。清单包含`cases`列表，每项提供`id`、相对清单位置的`input_path`与`schema_path`，可提供`sha256`；可选`seed_kb`只指向既定初始库。

评测专用传输层设置`max_tokens=4096`，并记录每个请求实际返回的用量，包括结构修复请求。该参数不应被解释为所有模型的总计费用量硬上限：首轮百炼请求实际返回的输出Token包含超过4096的情况。新版评测对百炼Qwen请求显式设置`enable_thinking=false`，并更新评测Provider指纹；其他厂商不注入此专属参数。百炼混合思考模型支持通过该参数关闭思考模式，参见[百炼官方深度思考说明](https://docs.modelstudio.console.alibabacloud.com/zh/model-studio/deep-thinking)。普通运行及服务器`.env`不变，首轮材料不自动重跑。

UTF-8文本字节、图片预算和输出限制用于保守预估，不是供应商账单的精确计数。评测中的付费请求串行派发，避免图分支同时预留预算造成提前失败。流程取消时不取消已派发的请求，而是在退出前等待其响应并登记用量；排队但尚未派发的请求停止。未知用量时`token_accounting_complete=false`并停止后续调用，不能假定失败或取消的请求免费。停止报告保留已尝试的材料及剩余未处理材料，不将正常预算停止显示为未捕获异常。此保守行为只作用于该评测入口，不改变普通Provider的重试策略。
