# PrismKE 隔离审核闭环验收报告

日期：2026-09-16。开发分支：`dev/v0.4`。本轮不合并 `main`，不创建发布标签。

## 结论与边界

审核界面、安全导入、审核专用状态图、提交预览及隔离 Mock 闭环已经实现。服务器通用测试为 **203 项通过、4 项跳过**；独立 Neo4j 实机测试为 **12 项通过**，包含审核后写图和补偿回滚。

ContinueMKGC README 的真实副本仍停在实体审核，**三条任务都未批准**。这份真实材料尚未完成审核后写图闭环；真实结论由用户确认，不能用合成验收替代。本轮新增百炼调用为零，不调整实体阈值、答案或初始候选库。

## 交付能力

- 实体/事实任务表、运行和风险筛选、候选选择与评分分解，无需手填任务和候选 ID。
- 提及原文、关联候选事实、文本位置和区域证据预览；读取失败明确显示错误。
- 冲突双方事实及证据并排展示，独立审核，不默认选择胜者。
- 占位名称、跨语言身份和作者/开发者关系疑点提示，不自动改名或合并。
- 审核人、意见与决定持久化；文件锁防止并发变更，同一任务不能重复覆盖。
- 原评测只读导入：校验摘要与检查点一致性、Provider 指纹、Schema、证据哈希、bbox 和实体引用。
- 接续状态图没有解析、OCR、LLM/VLM 抽取或实体召回节点；不创建真实 Provider，保留原调用记录。
- 待审核阻止恢复，待提交预览阻止自动写图，显式确认后才提交；失败提交可再次显式确认恢复。
- CLI、API 和 Gradio 复用应用服务；旧 HTTP 审核请求保持兼容，新增审核人和意见字段。

## 自动验收

| 场景 | 结果 |
|---|---|
| 原流程、Provider、证据和预算测试 | 通用测试通过，未调用百炼 |
| 专用评测指纹接续 | 未创建真实 LLM/OCR/VLM 客户端，历史调用记录不增加 |
| 导入失败保护 | 已存在目标、证据篡改、错误暂停点、摘要/检查点不一致均拒绝 |
| 未审核/重复审核 | 未完成不能继续；已处理任务不能覆盖 |
| 提交预览 | 审核后停在 `prepare_graph_commit`，图谱保持原状态 |
| JSON 写图与回滚 | 明确确认后提交，补偿回滚保留两条 Revision |
| Neo4j 写图与回滚 | 独立实例单事务提交、幂等、父版本校验、补偿回滚通过 |
| 事务失败 | JSON 图文件字节不变；失败节点被记录，可重试确认 |
| 冲突处理 | 批准一方后另一方仍待审，拒绝另一方后仅提交获批事实 |
| API | 鉴权、详情读取、审核、恢复保护通过 |

默认测试跳过三个需真实 Neo4j 的既有测试和一个新增 Neo4j 审核闭环测试。四项均在单独的实机测试命令中执行，并非未验证的保留项。Windows 另外跳过六项 POSIX 运维脚本测试，服务器已经执行。

独立 Neo4j 使用 `runtime/review-neo4j-test` 的数据、日志和 PID 目录，回环端口为 `17474/17687`，复用程序二进制，不使用生产数据库目录。测试完成后停止该实例。
