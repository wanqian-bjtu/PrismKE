## 三条实体审核

1. 打开“实体审核”，在“运行”中选择唯一的导入运行，确认实体待审核数为 3。
2. 选择 Xiang Chen，阅读关联事实、作者列表原文及候选评分。候选得分高不代表它就是同一个人。
3. 选择审核动作，填写你的审核人名称和意见，点击“提交当前审核”。页面会刷新，并选中下一条待审核任务。
4. 按相同步骤处理 Jintian Zhang 和 Shumin Deng。三条完成后再点击“继续处理”。

以下仅是依据当前 README 的建议，尚未替你提交决定：

| 提及 | 原文依据 | 建议 | 不应该做的事 |
|---|---|---|---|
| Xiang Chen | README BibTeX 的 `author` 列表 | 创建新实体 | 不要因为共同作者上下文而链接到 Huajun Chen 或 Ningyu Zhang |
| Jintian Zhang | 同一作者列表 | 按原文名称创建新实体 | 暂不将 Jintian/Jingtian 两种拼写当作已证实的同一人 |
| Shumin Deng | 同一作者列表 | 创建新实体 | 不要链接到召回的其他作者 |

三条都关联 `Continual Multimodal Knowledge Graph Construction authored_by <姓名>`。作者列表能够支持论文署名，不应直接改写成系统开发者关系。后续发现可靠的跨文档身份依据时，再另行提出合并建议。

“创建新实体”使用这次解析已有的草稿名称、类型及稳定 ID，并不调用模型；“拒绝提及”会排除含该提及的候选事实。当前页面不提供实体改名或批量批准。

## 后续事实审核与提交

继续处理后可能进入“事实审核”，这是正常的第二层审核，不代表实体审核失败。

1. 在“事实审核”选择同一个运行。逐条核对主谓宾、置信度和当前证据。
2. 冲突事实会并排展示。你的决定只作用于当前事实，不会默认批准或拒绝另一方；切换任务可以独立审核另一条。
3. 缺失或损坏证据会显示读取失败。请先排查，不要把空白预览当作证据成立。
4. 所有待审核事实处理完成后，点击“继续处理”。系统停在隔离提交预览，不会自动写图。
5. 检查实体、事实、冲突、证据数量及父版本。确认后勾选提交确认，再点击“确认写入隔离图谱”。该按钮要求填写审核人。
6. 在“图谱”“证据”“版本”查看结果。补偿回滚必须再次确认，历史 Revision 不会被删除。

如果候选违反 Schema 的主客体类型约束，或使用严格 Schema 中不存在的关系，隔离接续会将其保留在“事实审核”，标记为 `schema_blocked`，显示原候选和证据。这类任务仅允许“拒绝事实”，不能批准写图，也不会自动交换主客体或添加关系。正常候选仍可继续独立审核；所有任务处理完后才允许进入提交预览。普通抽取流程仍采用原来的严格校验。

## 服务器工作区

```text

监听：127.0.0.1:8001

```

服务器重启后，在项目目录重新启动独立工作台：

```bash
cd /root/autodl-tmp/PrismKE
tmux new-session -d -s prismke-review \
  'cd /root/autodl-tmp/PrismKE && PRISMKE_RUNTIME_DIR=runtime/review_workspaces/continuemkgc_20260916 PRISMKE_GRAPH_STORE=json PRISMKE_EMBEDDING_PROVIDER=disabled PRISMKE_API_HOST=127.0.0.1 PRISMKE_API_PORT=8001 /root/miniconda3/envs/prismke/bin/uv run prismke serve'
```

已有 `prismke-review` 会话时不要重复执行启动命令。原 8000 端口上的生产工作台不是本轮真实材料的审核入口。

## 导入其他运行

```bash
uv run prismke import-review-run \
  --source runtime/evaluation/某次成功评测 \
  --run-id 'run:某个运行ID' \
  --target runtime/review_workspaces/一个不存在的新目录
```

只允许导入当前兼容版本中、已经完成抽取且暂停在实体或事实审核位置的运行。目录不能重叠，目标不能覆盖。工具验证检查点、模型指纹、证据哈希、bbox 和实体引用后复制数据；审核专用状态图中没有解析、OCR、抽取或实体召回节点。

接续保留原模型调用记录作为来源信息，不新增百炼调用。本轮没有校准实体阈值，也不会将人工待审核结果计为自动链接成功。
