# PrismKE v0.10 三 Agent 隔离联调报告

## 范围

开发分支 `dev/v0.10`，软件版本 `0.10.0.dev0`，流程协议 `0.10.0`。稳定生产版本仍是 `v0.9.2`。服务器从开发分支建立独立检出，使用独立 JSON GraphStore、运行目录和持久化请求账本；没有连接生产 Neo4j，也没有批准真实审核任务。

本轮采用服务器现有 `qwen3.7-flash` 文本/视觉配置及已缓存的 BGE-M3。没有下载模型或主动充值。真实请求总上限 30,000 Token，27,000 Token 停止派发。原始运行结果和账本留在服务器被 Git 忽略的 `runtime/agent-validation/v010-20260922-01/`。

三份运行均留下抽取、治理、融合审核 Agent 的脱敏轨迹。另有一次**不写图**的真实语义建议探针消耗 210 Token，模型建议链接已给候选，但没有自动应用该建议。总计 **3,697 Token**，账本已结算且用量可核对，未达到停止线。

英文样例的 Schema domain/range 错误由硬校验阻断，说明防线生效；同时也表明该样例的抽取质量未通过，不能写成成功产出正式 Claim。中文图文样例停在实体审核，未由系统擅自完成后续写图。当前三个样例没有在正常工作流中触发“灰区实体建议”或“复杂事实组语义建议”；这些路径已通过 Mock/MockTransport 自动测试，真实探针只验证了前者的服务连通与候选 ID 约束。

## 自动与页面验收

- 本地与服务器 Ruff、Mypy 和完整 pytest 通过。服务器隔离 Neo4j 测试 **102 项通过**；其测试数据位于新检出的独立运行目录，执行后测试实例已停止。这组测试与完整 pytest 有交集，不相加。
- 合成 Mock 运行可在 Web“Agent 协作”页面查看三个 Agent 的步骤、工具、决定、状态和结构化交接。桌面及 390px 移动视口已检查；移动端轨迹表在自身区域横向滚动，不引起页面级溢出。
- 图谱提交仍由确定性服务执行；模型建议不直接写 Cypher，不绕过 Schema、证据和人工审核边界。

## 后续问题

1. 英文别名样例出现两条 domain/range 问题，需要后续检查 Prompt 对主客体类型和关系方向的表达。此次不为单一样例硬编码修复。
2. 正常工作流中的真实语义建议触发率仍需更有针对性的灰区样例验证；本轮不能宣称这一路径已经完成充分真实评测。
3. OCR 真实运行、结构化表格和图表专用解析不在此次小规模联调内。表格与图表仍应在后续版本独立实现和评测。
4. 旧 `v0.9.2` 检查点只能由对应发布代码接续，不能用 v0.10 流程恢复。

本报告仅证明三 Agent 工程协作与小规模真实调用可运行，不代表开放域抽取质量或所有事实已经人工确认。`v0.10.0` 尚未发布。
