## 浏览器与证据

仅对新的合成工作区执行动作，完成：实体审核 → 校验问题排除 → 冲突事实审核 → 显式提交 → 历史事件及证据查看 → 纠正预览/确认 → 显式补偿提交 → Revision 回滚。

浏览器记录位于本地忽略目录 runtime/browser-v06-qa-delivery/browser-result.json；同目录保存桌面/移动截图。记录 passed=true、pageErrors=[]、mobileOverflow=false。纠正预览证据内容通过实际页面断言，不以空白预览冒充成功。最终代码也验证了补偿提交摘要的实际 before/after 变更，并人工查看桌面/移动截图。

测试工作区为服务器 runtime/browser-review-v06-delivery；Web 仅监听本机 8004，本地 SSH 转发入口为 http://127.0.0.1:18004/ui/。此入口是合成验收工作台，不是原真实审核工作台。

最终测试过程中发现复用数据库的合成名称与旧夹具重名，导致解析器合理进入消歧。通过独立主体/对象名称隔离夹具后全量复测通过，没有放宽解析阈值或改动答案。
