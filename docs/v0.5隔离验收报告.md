## v0.5 实现

代码验收基点为 `156dfc4`，流程协议为 `0.5.0`，校验策略为 `validation-v1`。

| 范围 | 结果 |
|---|---|
| 公共模型 | 独立问题、结果、排除审计与提交校验上下文 |
| Provider | 逐项结构隔离；整批 JSON 与网络失败仍阻断节点 |
| 领域规则 | 类型、关系、domain/range、实体与视觉引用、证据完整性和定位 |
| 普通与隔离流程 | 共用规则；违规候选保留、正常候选继续、开放问题暂停提交 |

| 接口 | validate-run、只读校验 API、独立人工排除 API 与重复提交保护 |
| 页面 | 运行及问题选择、阶段/代码/状态筛选、证据、确认排除及审计 |

## 自动与浏览器验收

- Ruff 通过；Mypy 检查 72 个源文件通过。
- 服务器完整 pytest：246 项通过、5 项跳过。跳过项均为需要独立 Neo4j 实例的测试。
- 独立 Neo4j 专项套件：55 项通过，包含 JSON 与 Neo4j 的隔离流程；使用 17474/17687 端口，不连接生产数据库。
- CLI 对有阻断问题的合成运行返回退出码 1，报告 UNKNOWN_RELATION，源运行文件哈希不变。
- 直接提交缺少上下文、未知关系、损坏证据、错误实体引用及不支持的校验策略均被拒绝；失败后 graph.json 字节不变。
- 预览后篡改证据仍无法提交；实体更新及实体单独回滚不能绕过已有活动事实校验。
- 旧迁移 dry-run 报告缺失上下文；实际迁移拒绝猜测补齐。
- 浏览器使用 Mock 合成工作区，在 1440×1000、390×844 视口完成：实体审核 → 问题排除 → 冲突事实独立批准/拒绝 → 提交预览 → 确认写图 → 补偿回滚。
- 浏览器无 pageerror，移动端无页面横向溢出。证据文字实际加载后截图；纯文本证据不显示空图片面板。回滚保留原 Revision 与补偿 Revision。

浏览器脚本：`scripts/review_browser_smoke.cjs`。截图与机器结果留在忽略的 `runtime/browser-qa-v05-final/`；完整合成审核运行留在服务器 `runtime/browser-validation-review-v4/`。

## 安全与边界

- 本轮使用 Mock 或 httpx.MockTransport，不调用百炼、不下载模型、不调整实体阈值。
- 不修改生产图谱、原评测结果或真实审核决定，不批量批准真实任务。
- 原文、证据、检查点、运行结果、模型和密钥不提交 Git。
- 字符、页码与 bbox 校验只说明引用及定位约束，不证明图像理解或事实语义正确。
- v0.4 运行可只读查看，但不能在 v0.5 恢复或自动导入；已有审核接续使用发布的 v0.4.1。
- Docker、本地模型能力和新的真实模型全量评测不在本轮验收范围。
- 案例检索、Reflection、历史审核纠正和任务队列未实现；v0.5 发布另行确认。

操作、问题代码和迁移方式见 [统一校验说明](v0.5统一校验说明.md)。
