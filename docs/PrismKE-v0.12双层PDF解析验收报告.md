## 已确认行为

- 同一逻辑 MinerU 请求恢复时复用原 job，不重复上传或新建解析任务；
- Markdown 不作为证据，最终证据来自原 PDF、MiddleJson locator 和派生资产；
- MiddleJson 或派生资产被篡改后，EvidenceStore 验证失败；
- 自动模式选择 MinerU 但服务不可用时进入 `parser_blocked`；
- 具名降级事件不可变保存，同请求幂等返回，变更理由会被拒绝。
