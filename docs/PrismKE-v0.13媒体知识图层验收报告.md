## 4. 真实 VLM 验收

验收在服务器隔离目录执行，使用 `qwen3.7-flash`，不连接 GraphStore，未访问或修改生产图谱。所有请求串行发送，并由同一不可重置账本累计计费；停止线为 27,000 Token，硬上限为 30,000 Token。

| 样例 | 媒体对象 | 关键结果 | 证据验证 |
|---|---:|---|---|
| 产品照片 | 1 Content / 1 Occurrence | 2 个 DEPICTS 候选、1 个视觉断言、3 个审核任务 | 通过 |
| 表格/图表 | 1 Content / 1 Occurrence | 1 个 DEPICTS 候选、2 个视觉断言、3 个审核任务 | 通过 |
| 图文冲突 | 1 Content / 1 Occurrence | 1 个 DEPICTS 候选、2 个视觉断言、1 个冲突审核 | 通过 |

- 最终三样例调用使用 6,079 Token；包含前置探针在内的累计总量为 16,215 Token。
- 三组样例的活动媒体证据、区域 EvidenceRef 和源文件哈希回读率均为 100%。
- 图文冲突没有覆盖文本结论，状态差异被标记为 `cross_modal_attribute_conflict` 并进入人工审核。
- 原始样例、模型回复和请求正文仅存在于受控运行过程，不进入 Git 或验收报告。
- 验收命令为 `scripts/validate_media_v013.py`；该命令拒绝复用不完整账本，并在用量未知、鉴权失败或请求结果不确定时停止后续调用。

## 5. 硬边界

- 未审核视觉独有知识写图数量为 0。
- 审核事件必须批准当前候选，不能跨任务复用。
- 图片篡改后事务被阻断，图中不出现半写入对象。
- 共享媒体内容在补偿回滚后保留，发生位置、关系和断言被关闭。
- 图文属性冲突进入视觉审核，文本结论不被覆盖。
- API 与页面不显示 Base64、服务器绝对路径、密钥或密码。

## 6. 未进入本版

历史媒体迁移、图片向量检索、普通文本属性/事件写图和视觉模型训练继续留待后续版本。真实开放域效果不能由合成样例替代，应另建独立评测集。
